// CONFIDENCE SCORING
The % score tells you how complete a recovered file is. Based on whether file header AND footer were both found.
90–99% — HIGH CONFIDENCE
Both header AND footer found. File is almost certainly complete.
70–89% — MEDIUM
Header found, size calculated from internal fields. Likely complete.
50–69% — LOW
Header found but no footer. Size estimated. May be cut off.
<50% — UNCERTAIN
Very short match or ambiguous bytes. Could be false positive.

// HOW RECOVERY WORKS
1. Reads raw drive sectors — bypasses file system
2. Searches for file magic bytes (e.g. FF D8 FF = JPEG)
3. Finds file footer to determine exact size
4. Scores confidence: header+footer=90%+, estimated=50–70%
5. Extracts bytes — download as ZIP or save to Desktop
